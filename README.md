# Workstation Media · 自媒体人工作台

**把热点、对标、选题、写稿、拍摄、排期和复盘，放进同一个内容工作室。**

面向短视频口播创作者、多 IP 运营者和小型内容工作室的 PC 端工具。采用单文件 HTML，下载后用浏览器打开即可使用；核心功能无需安装、注册或配置 AI。

## 它能帮你做什么

以「IP → 平台账号 → 内容 → 每个账号的发布记录」组织创作资产。一条稿子可以安排给多个账号，发布后的数据分别记录和比较。

| 模块 | 主要用途 |
| --- | --- |
| 工作室 | 场景式总览，查看热点、节点、排期、待办与近 7 天更新进度；切换日常、拍摄、排期、数据模式 |
| IP 与账号 | 管理人设、赛道、目标观众、更新目标和各平台账号；查看 IP × 平台覆盖矩阵 |
| 热点雷达 | 手动录入热点，标记适用 IP，整理切入角度并转成选题；直达外部热榜 |
| 对标账号 | 录入对标作品、互动数据和口播稿，拆解开头、结构与结尾；借选题、套结构写稿 |
| 选题池 | 标题公式、五维评分、雷达图和 S/A/B/C 评级，帮助挑选值得投入的选题 |
| 文案工坊 | 分区写开头、正文、结尾、封面与标签，估算口播时长，完成 10 项文案体检 |
| 拍摄剪辑 | 拍摄日程、自动拆分镜、开拍检查、景别速查、全屏提词器（速度／字号／镜像） |
| 发布排期 | 安排发布时间和目标账号，预览封面、核对发布准备、复制文案并登记已发布 |
| 数据复盘 | 手动回填各账号数据，查看象限图、趋势、IP／账号对比、单条诊断和周报 |
| AI 助手 | 对话与 16 个任务模板，可带入 IP 档案、稿件和最近 14 天的数据；部分结果可填回文案或选题池 |
| 设置 | 工作室信息、主理人形象、数据参考线、AI 接口、备份恢复与示例数据 |

## 三分钟上手

1. 点击上方「下载完整项目」，或者在 GitHub 选择 **Code → Download ZIP**。
2. 解压后，双击 **`自媒体人工作台.html`**，用桌面浏览器打开。GitHub 的文件预览页只显示源码，需下载到本机运行。
3. 首次打开时选择主理人形象、填写称呼和工作室名称。想先体验，选择「先看看示例工作室」；正式开始，选择「直接用我自己的」并填写第一个 IP。
4. 进入「IP 与账号」，补充人设和平台账号，再按「热点／对标 → 选题 → 文案 → 拍摄 → 排期 → 复盘」使用。
5. 定期进入 **设置 → 数据与备份 → 导出备份**，把 JSON 文件保存好。

没有构建步骤，也不需要 Node.js、数据库或后端服务。请使用支持本地存储的现代桌面浏览器；界面主要面向 PC。

## 不接 AI，也能用

IP 和账号管理、选题评分、规则式文案体检、分镜、提词器、排期与复盘等功能均在浏览器内运行。未配置 AI 时，AI 模板会整理出提示词，供你复制到其他 AI 网页版使用。

如果希望在工作台内生成内容，可在 **设置 → AI 接口** 填写服务商、API Key、Base URL 和模型名称，再点击「测试连接」。代码内置 OpenAI 兼容接口和 Claude 消息接口适配，并提供 Ollama 本地模型预设。

模型名称和可用权限以你使用的服务商控制台为准；预填模型名不代表一定可用。接口是否支持浏览器直连也取决于服务商的跨域配置。详见[AI 使用说明](使用说明.md#ai-助手与接口配置)。

## 数据如何保存

- 业务数据自动保存在当前浏览器的 `localStorage` 中，不会自动同步到 GitHub、其他浏览器或其他设备。仅复制 HTML 文件不会带走业务数据。
- 换浏览器、移动或改名 HTML、清理浏览器数据、升级版本前，先导出备份；在新的使用环境中通过「从备份恢复」导入。
- 备份导出会清空配置中的 API Key 字段，但仍包含你的稿件、账号资料、发布数据与 AI 对话，请自行妥善保管。
- **调用 AI 时，提示词及选中的上下文会发送到你配置的服务商。** 本地存储不等于 AI 请求不出网；外部热榜链接也需要联网。
- 如果浏览器禁止本地存储，软件会退回临时内存模式，关闭页面后不能保留数据。

## 当前版本边界

- 当前代码通过界面最多创建 **8 个 IP**。原始规划中的「IP 数量不限」尚未与实现一致。
- 「标记已发布」用于登记本地记录，**不会代你向抖音、小红书等平台上传视频或发布内容**；需要先在对应平台完成发布。
- 热点、粉丝与作品数据需要手动录入；当前没有自动抓榜、平台自动回填、云同步、成员权限或多人实时协作。
- 「拍摄剪辑」提供创作辅助工具，不包含视频录制、剪辑渲染或平台上传功能。当前速查功能为「景别速查」。
- 本仓库仅包含提供的正式版 HTML。原始规划提到的录屏版、页面提到的 `ai-proxy.js` 均未随源文件提供，因此本次未打包。
- 评分、诊断和极限词检查是创作参考，不保证平台审核结果或传播效果；数据参考线可按账号情况调整。

原始功能规划作为设计资料保留；当前使用行为以 HTML 实现和本仓库的使用说明为准。
